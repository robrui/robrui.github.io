Edge Cases in scipy.signal.savgol_coeffs

scipy#25070  ·  April 2025  ·  ~13 min read
TL;DR: scipy.signal.savgol_coeffs computes Savitzky-Golay filter coefficients via least-squares polynomial fitting. It had several edge-case bugs: (1) missing validation for window_length <= order, (2) strange behavior with window_length=1, and (3) incorrect coefficient normalization for high-order polynomials. The fix adds proper parameter validation and correct coefficient normalization.

1. Background: The Savitzky-Golay Filter

The Savitzky-Golay (SG) filter is one of the most widely used digital signal processing tools. It smooths a signal by fitting successive sub-sets of adjacent data points with a low-degree polynomial using linear least squares.

Given a signal $y[n]$, the filter computes each smoothed point as:

$$ \hat{y}[i] = \sum_{k=-M}^{M} c_k \; y[i + k] $$

where $M = \lfloor W/2 \rfloor$ and $W$ is the window length. The coefficients $c_k$ are computed by fitting a polynomial of degree $d$ (the order) to the $W$ points centered at $i$, and then evaluating the polynomial at the center.

Mathematically, for a window of $W = 2M + 1$ points and polynomial order $d$:

$$ \mathbf{A} = \begin{bmatrix} (-M)^0 & (-M)^1 & \cdots & (-M)^d \\ (-M+1)^0 & (-M+1)^1 & \cdots & (-M+1)^d \\ \vdots & \vdots & \ddots & \vdots \\ M^0 & M^1 & \cdots & M^d \end{bmatrix} \in \mathbb{R}^{W \times (d+1)} $$

The least-squares solution gives the polynomial coefficients $\beta$:

$$ \beta = (\mathbf{A}^T \mathbf{A})^{-1} \mathbf{A}^T \mathbf{y} $$

The filter coefficients $c_k$ are simply the first row of $(\mathbf{A}^T \mathbf{A})^{-1} \mathbf{A}^T$ — i.e., the linear coefficients that extract the constant term of the fitted polynomial.

2. Three Edge-Case Bugs

Bug #1: window_length <= order Not Validated

The most fundamental constraint of the Savitzky-Golay filter is that the polynomial order must be less than the window length. If $d \geq W$, the least-squares fit is underdetermined — there are more polynomial coefficients than data points. 

from scipy.signal import savgol_coeffs

# This should raise an error but silently returned garbage
coeffs = savgol_coeffs(window_length=5, order=5)
# ❌ order=5 and window_length=5 means 6 polynomial coefficients
# for only 5 data points — rank-deficient system!

The minimum requirement is $d < W$ (or equivalently, $d \leq W - 1$). Many textbooks state $d \leq W - 2$ as the practical limit because the highest-degree polynomial is often poorly conditioned.

Bug #2: window_length=1 Division by Zero

With window_length=1, there is only one data point. The Vandermonde matrix has a single row, and the least-squares system becomes degenerate. The function either crashed with a LinAlgError or returned coefficients that didn't satisfy the Savitzky-Golay properties. 

# window_length=1: single point, single coefficient
coeffs = savgol_coeffs(window_length=1, order=0)
# Expected: coeffs = [1.0] (trivial — identity filter)
# Bug: crash or wrong result

Bug #3: Incorrect Normalization for High Order

For certain combinations of window length and high polynomial order, the computed coefficients didn't preserve the DC gain of 1. A proper Savitzky-Golay filter must satisfy $\sum c_k = 1$ for order ≥ 1 (the method preserves the mean of a constant signal). The buggy normalization code failed for edge-case parameters.

3. The Fix: Proper Validation and Robust Computation

The PR addresses all three bugs with comprehensive parameter validation and a numerically stable coefficient computation path: 

def savgol_coeffs(window_length, order, deriv=0, delta=1.0, pos=None, use="conv"):
    # ✅ Validate window_length
    if window_length < 1:
        raise ValueError("window_length must be >= 1")
    if not isinstance(window_length, (int, np.integer)):
        raise TypeError("window_length must be an integer")
    
    # ✅ Validate order < window_length
    if order >= window_length:
        raise ValueError(
            f"order must be less than window_length "
            f"(got order={order}, window_length={window_length})"
        )
    
    # ✅ Handle window_length=1 trivially
    if window_length == 1:
        return np.array([1.0])
    
    # ... rest of the computation with improved normalization
    half = window_length // 2
    x = np.arange(-half, half + 1)
    A = np.vander(x, order + 1, increasing=True)
    
    # Solve least-squares
    _, coeffs, _, _ = np.linalg.lstsq(A, np.eye(window_length)[half], rcond=None)
    
    # ✅ Normalize to ensure DC gain = 1
    coeffs = coeffs / coeffs.sum()
    
    return coeffs

4. Testing the Fix

from scipy.signal import savgol_coeffs
import numpy as np

def test_savgol_coeffs():
    """Verify Savitzky-Golay properties."""
    
    # 1. DC gain must be 1
    coeffs = savgol_coeffs(window_length=7, order=3)
    assert np.isclose(coeffs.sum(), 1.0), \
        f"DC gain != 1: {coeffs.sum()}"
    
    # 2. Coefficients must be symmetric (even function)
    assert np.allclose(coeffs, coeffs[::-1]), \
        "SG coefficients must be symmetric"
    
    # 3. window_length=1, order=0 returns [1.0]
    coeffs1 = savgol_coeffs(window_length=1, order=0)
    assert np.array_equal(coeffs1, [1.0]), \
        f"window_length=1 failed: {coeffs1}"
    
    # 4. order >= window_length raises ValueError
    try:
        savgol_coeffs(window_length=5, order=5)
        assert False, "Should have raised ValueError"
    except ValueError:
        pass  # Expected
    
    # 5. Even-order fitting on a quadratic
    x = np.linspace(0, 5, 50)
    y = x**2 + np.random.randn(50) * 0.5
    from scipy.signal import savgol_filter
    y_smooth = savgol_filter(y, window_length=11, order=3)
    # Smooth version should still be approximately x^2
    assert np.corrcoef(y_smooth, x**2)[0, 1] > 0.99, \
        "SG filter failed to preserve quadratic trend"
    
    print("All tests passed ✓")

5. Using Savitzky-Golay in Practice

import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import savgol_filter, savgol_coeffs

# Generate a noisy ECG-like signal
t = np.linspace(0, 2, 500)
clean = np.sin(2 * np.pi * 5 * t) + 0.5 * np.sin(2 * np.pi * 20 * t)
noisy = clean + 0.3 * np.random.randn(500)

# Apply SG filter with optimal parameters
# Window length: odd number ≥ order + 2
# Lower order = more smoothing, higher order = preserves features
y_smooth = savgol_filter(noisy, window_length=21, order=3)

# For derivative estimation (e.g., velocity from position)
# Use deriv=1 to get the first derivative
coeffs_1st = savgol_coeffs(11, 3, deriv=1, delta=0.01)

The key parameters to tune:

  • window_length: Larger = smoother but more lag. Must be odd.
  • order: Higher = preserves more detail but less noise reduction. Must be < window_length.
  • deriv: 0 for smoothing, 1 for first derivative, etc.

6. Why This Matters

The Savitzky-Golay filter is used by essentially anyone working with real-world signal data:

  • Spectroscopy: Smoothing Raman, IR, and UV-Vis spectra
  • Bio-signals: ECG baseline wander removal, EMG smoothing
  • Sensor data: Accelerometer, gyroscope denoising
  • Financial time series: Trend extraction from noisy price data
  • Analytical chemistry: Chromatogram peak smoothing

The savgol_coeffs function is the computational kernel behind scipy.signal.savgol_filter, which is itself one of SciPy's most downloaded functions. Edge-case bugs in coefficient computation can produce silently corrupted filtering results for specific parameter combinations — the kind of bug that users discover months later in production.

By adding proper validation and robust normalization, this PR ensures that savgol_coeffs either returns correct coefficients or raises a clear error — no silent failures.
